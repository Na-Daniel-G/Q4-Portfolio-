### Step 1 (Static vs Relative):

- Add in css ```position: relative; top: 20px; left: 20px;``` to .sidebar.

- Guided Question: What changed compared to the default static positioning? Try to give different values to top and left or you can change it to bottom, right.

- Answer: It movied 20px to the bottom and 20px to the right relative to the static. If I change the valuse of left and top, it adjust the distance from  the static to the new position. If you use right or bottom it moves it to the top and to the left, you would also get the same effect if you use negative values for the left and top.

### Step 2 (Fixed):

- Add in css ```position: fixed; bottom: 0; width: 100%;``` to .footer.

- Guided Question: What happens when you scroll the page? Why does the footer behave differently from position relative?

- Answer: The footer stays pinned to the bottom of the screen no matter how far you scroll. Relative is still part of the normal flow and its offset is measured from its own original position while fixed is completely removed from the flow and positioned relative to the viewport , which is why it doesn't scroll away.

### Step 3 (Absolute):

- Add in css ```position: absolute; top: 66px; left: 200px;``` to .content.

- Guided Question: What is the effect of position: absolute on an element? How is it different from fixed?

- Answer: The element is pulled out of the normal flow, no space is reserved for it. It then positions itself relative to its nearest ancestor that has a non-static position. If none exists, it defaults to the html element.
The difference between absolute and fixed are absolute scrolls with the document, while fixed is always anchored to the viewport and never scrolls away.

### Step 4 : (Absolute)

- Add in html ```<div class="notice">Notice!</div>``` and include the css below:

```css
.notice {
    position: absolute;
    top: 60px;
    left: 400px;
    background: orange;
    padding: 10px;
    z-index: 2;
}
```

- Give .content a z-index: 1.

- Guided Question: Why does the notice appear on top of the content? What happens if you swap the z‑index values?

- Answer: 
Both elements compete in the same area. The one with the higher z-index wins and gets painted on top. .notice has z-index: 2 vs .content's z-index: 1, so the notice overlaps. If you swap the z-index values, .content would be painted on top, covering/hiding the "Notice!" text wherever they overlap.
